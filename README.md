# Life Insurance Pricing & Valuation Model — Excel

An actuarial life insurance pricing and valuation model developed in **Microsoft Excel**. The project applies mortality assumptions, commutation functions, actuarial present values, premium calculations, reserves, and bonus structures to a portfolio of life insurance policies.

## Project Overview

This project demonstrates how actuarial techniques can be implemented in Excel to analyze and value different types of life insurance policies.

The model includes **109 policyholders** and covers several life insurance products, including:

- Whole Life Insurance
- Endowment Insurance
- Term Insurance
- Non-Participating Policies
- Participating Policies

The model uses a mortality table and actuarial commutation functions to calculate premiums and policy values.

## Objectives

The main objectives of the project are to:

- Calculate actuarial present values for life insurance benefits.
- Calculate net premiums for different insurance products.
- Calculate policy reserves at different durations.
- Analyze the impact of reversionary bonuses.
- Compare simple and compound reversionary bonus structures.
- Analyze premiums and reserves across different policy types.
- Apply actuarial valuation techniques using Excel.

## Actuarial Methods

The model applies several actuarial concepts, including:

### Mortality Table

A mortality table is used to determine survival and death probabilities for different ages.

### Commutation Functions

The model uses standard actuarial commutation functions, including:

- $D_x$
- $N_x$
- $S_x$
- $C_x$
- $M_x$
- $R_x$

These functions are used to simplify the calculation of actuarial present values and premiums.

### Actuarial Present Value

The model calculates the present value of future insurance benefits using mortality and interest assumptions.

### Net Premium

Net premiums are calculated based on the actuarial present value of future benefits.

### Policy Reserves

The model calculates reserves representing the actuarial value of future benefits less the actuarial value of future premiums.

### Reversionary Bonuses

The model also considers:

- Simple reversionary bonuses
- Compound reversionary bonuses

This allows the impact of bonus structures on policy values and reserves to be analyzed.
